How It Works

1. Send a request → get 402 Payment Required with USDC price

2. Sign payment with your wallet

3. Retry with PAYMENT-SIGNATURE header → get result

Example

Step 1: Request without payment

curl -X POST {{ base_url }}/v1/wavespeed/wavespeed-ai/z-image/turbo \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A sunset over mountains"}'

# Response: 402 Payment Required
# {"accepts": [{"network": "base", "price": "0.00625", ...}]}

Step 2: Retry with signed payment

curl -X POST {{ base_url }}/v1/wavespeed/wavespeed-ai/z-image/turbo \
  -H "Content-Type: application/json" \
  -H "PAYMENT-SIGNATURE: <base64-signed-payload>" \
  -d '{"prompt": "A sunset over mountains"}'

# Response: 200 OK
# {"data": {"outputs": ["https://...image.png"], ...}}

Error Format

If the provider rejects a request, payment is not settled — you keep your USDC:

{
  "error": "size does not meet the constraints.",
  "provider": "wavespeed",
  "status": 502
}
Payment is settled only on success (HTTP 200). On any error, no USDC is transferred.
